Kobi Fitness – קבצי האפליקציה

מה יש כאן:
- index.html: האפליקציה בעברית, מותאמת לנייד.
- manifest.webmanifest + icon.svg: הגדרות ואייקון למסך הבית.
- sw.js: תמיכה בסיסית בעבודה לא מקוונת לאחר טעינה ראשונה.

חשוב:
כדי להתקין כאפליקציה עם אייקון במסך הבית, יש להעלות את כל הקבצים לכתובת HTTPS (למשל GitHub Pages או שירות אירוח סטטי).
פתיחת index.html מקומית מאפשרת להשתמש באפליקציה בדפדפן, אבל אינה מאפשרת התקנת PWA מלאה.
אחרי פרסום ב-HTTPS: לפתוח את הקישור ב-Chrome באנדרואיד > תפריט ⋮ > הוספה למסך הבית / התקנת אפליקציה.

הנתונים נשמרים ב-localStorage של הדפדפן במכשיר. ניקוי נתוני האתר עלול למחוק אותם. השתמש בכפתור ייצוא נתונים לגיבוי.
